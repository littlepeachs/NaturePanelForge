Scientific figure-to-code workflow

NaturePanelForge

A code-first workflow for extracting Nature-level scientific figure panels, reconstructing statistical panels as editable Python code, and inspecting refined reproductions in a live gallery.

Open Live Gallery GitHub Repository Intro and Methods
Panel Split Convert compound full figures into reviewed, metadata-rich panel crops.
Code Reproduce Use a Codex write/review loop to render panels as Python, PNG, and PDF.
Final Refine Polish typography, overlaps, edge visibility, and scientific labels.

Large gallery images are served by the live gallery backend. This GitHub Pages site only hosts the project landing page and documentation.
