# Codex Reproduction Prompt Blueprint

Role: code-writing agent plus review agent.

Goal: write executable Python plotting code that recreates the target statistical panel.

Requirements:

- Read `target.png`, `metadata.json`, `qwen_score.json`, and caption/description if available.
- Write `reproduce_panel.py`.
- Render `reproduce_panel.png` and `reproduce_panel.pdf`.
- Use code only. Do not paste or manually edit the target image.
- If the target has clipped text or clipped panel letters, do not intentionally reproduce the clipping. Draw the complete scientific figure.
- If a small schematic inset cannot be faithfully generated by code, simplify that schematic portion while preserving the statistical plot.
- Review the generated image against the target.
- If review fails, edit the Python code and rerender.
- Save `reproduce_panel_run_log.md`, `reproduce_panel_review_notes.md`, and `reproduce_panel_review_summary.json`.

Review focus:

- chart type
- data pattern
- layout
- axis range/ticks/labels
- legend/colorbar
- annotations and statistical marks
- visual clarity
- executable and editable code
